ABOUT THE PROJECT

Making Human Emotion Understandable

AI-Based Text and Speech Emotion Detection is an intelligent web application designed to analyze human communication. It combines text processing and speech recognition to identify emotional patterns.

The system can be useful in customer feedback analysis, education, virtual assistants, communication systems, surveys and other applications where understanding emotional context is important.
